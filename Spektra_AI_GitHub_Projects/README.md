# Spektra AI-Native Software Engineer Trainee – Portfolio Projects

Two starter portfolio projects:

1. **AI-Powered Resume Analyzer** – compare a PDF resume against a job description, discover matching/missing keywords, and optionally request AI suggestions.
2. **AI Study Buddy** – upload PDF/TXT notes, retrieve relevant passages, and optionally generate AI explanations, summaries, and quizzes.

Both apps are built with Python and Streamlit. AI API features are optional and require an OpenAI API key; local baseline functions can run without one.

Each project has its own README with setup instructions. Build, test, and customize these projects before listing them as completed on a resume.
